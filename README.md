- **退敌优先**：掠夺者所在房间允许超员，不受普通岗位容量、固定四人限制、库存或临时停产阻挡。按力量和已穿戴武器集中血量至少70%的在家成人，保留原岗位；敌人移入内部房间后追击，整场事件结束后复岗。停电、生产、训练、医疗或感情培养不阻止紧急增援；外出、儿童、倒下、重伤、姓名不唯一以及人工接手的人员不新派。其他事件中的人员不抽走，原岗位满员或不可用时保留记录等待。防守期间取消尚未提交的建设，暂停常规调岗和建设，约7秒复查；浏览器冻结、网络和原请求核对仍会延迟执行。健康阈值是脚本策略，不保证伤亡为零。
- **防守开关**：位于“探险、任务与养成”，应用综合发展推荐会开启。旧配置未保存该项时，随已启用的探险或养成开启；明确关闭后保持关闭。只在受袭房间允许超员，战后仍核对普通岗位容量。
- **等级解锁**：按居民、房间和深度计算等级分；待产及在建项目足够时等待，否则比较确有产出的升级来推进需要的建筑解锁。等级目标不再被误作养成人员预留，从建议接入实际升级，仍遵守原建设预算。
- **工坊按需值班**：同时开启自动升级和人员管理、建设额度非零时，为当前优先升级准备零件，计入零件保留量；有安全离岗人选和供料才建工坊或补现有岗位，完工后自动安排。已收零件和房间待收产出足够、供料会触及废料保留量或供应不足时，释放脚本安排的工坊人员，人工岗位不撤销。工坊加工由网站持续结算，不计作脚本建设支出；检查间隔或页面冻结可能导致超出目标的加工，不能承诺精确停在目标数量。
- **探险恢复**：原行程账本丢失时，核对七天内同页的出发、请求结果与成功日志，恢复原人物、行程和计划时长；其他动作的快照短暂漏掉探险时不再删除计划。缺证据、人工行程及深渊不猜测接管。探险同战力时再比较装备加成后的幸运，不降低战力去追幸运，也不宣称幸运增加汽水概率。
- **股市加载**：行情先于原生交易控件返回时有界等待，控件可用后继续原策略；持续不出现则返回并记录具体原因，不修改人工筛选、不放宽收益门槛。
- **每日目标**：读取网站的目标、实际进度与奖励，已完成时先领取再安排普通养成。废料／食物目标按零点前剩余时间保留必要的现有生产人员；建设优先兼顾有实际用途的项目，只差一次时也比较奖励能覆盖材料成本的有效生产升级，仍检查供电、停产储备和预算，不把未领取奖励算作资金。训练目标未完成时可超过原基础目标再练一格，完成后恢复原目标；不超过基础属性10。废土胜利仍按网站计数，不能用出发次数代替；制作装备、商队订单尚需手动，生育和事件受游戏时机限制，不能承诺每日三项全部完成。
- **免费互助**：在“探险、任务与养成”开启，综合发展推荐会同时开启每日目标和互助；升级安装保留已有配置，不擅自开启这两项。读取等级榜和参观资格，跳过本人、今天已帮助、对方受助上限、每周配对限制和资格不符对象，库存不足容纳奖励时等待。使用原生帮忙按钮及网站生成的指纹／原请求键，不点赞、不修改资格、不发消息。按绑定成功回执确认废料，脚本确认5次或网站报告自身奖励用尽后停止；人工帮助仍以网站上限为准。每个游戏日至多检查100个对象，每次访问仍有时限。
- **互助恢复**：未知回执不重发。当天原对象明确显示已帮助时可只读解除等待，但该笔奖励保持未知、不虚记收入；跨日、目标不符或仍无法确认时只暂停新增互助，其他玩法继续。日志不保存指纹或原请求键。截图每次13废料只是该时点报价，实际记网站回执数量。

## 开发验证

需要 Node.js 24 和本机 Chrome / Edge，也可用 `CHROME_PATH` 指定浏览器。无需安装第三方依赖。

浏览器回归按顺序执行，总时限60分钟；可以用 `ARKENGINE_TEST_PATTERN` 选择相关场景。当前版本的验证范围见上文；550 项单轮完整记录属于 v1.14.48 基线，504 项分组完整覆盖记录属于 v1.14.38。

浏览器启动时在原15秒期限内等待调试端口文件可读且两行内容完整，处理Windows临时占用或文件尚未出现；其他文件错误仍立即报告。故障注入已验证占用、缺失及半写入状态后可正常连接浏览器。

```powershell
node --check .\arkengine-auto-encounter.user.js
node --test .\arkengine-stock-core.test.mjs .\arkengine-shelter-core.test.mjs .\arkengine-shelter-campaign-core.test.mjs .\arkengine-shelter-allocation.test.mjs .\arkengine-shelter-gear.test.mjs .\arkengine-recovery-development.test.mjs .\arkengine-browser-test-runtime.test.mjs
node --test .\arkengine-auto-encounter.test.mjs
```

发布新版时同步增加脚本版本、日志导出版本及对应测试断言，然后重新生成元数据文件：

```powershell
node -e 'const fs=require("node:fs");const s=fs.readFileSync("arkengine-auto-encounter.user.js","utf8");const h=s.match(/^\/\/ ==UserScript==[\s\S]*?\/\/ ==\/UserScript==/);if(!h)throw Error("Missing userscript metadata");fs.writeFileSync("arkengine-auto-encounter.meta.js",h[0]+"\n");'
```

验证通过且取得发布授权后，将安装脚本与元数据文件一起提交并推送到 `main`。仓库只包含脚本、说明和测试；本地运行日志及账户数据不应提交。


## 设计参考

本次借鉴以下项目的原则，使用浏览器原生 API 实现，不引入第三方运行依赖：

- [Playwright locators](https://github.com/microsoft/playwright/blob/83b80cfb2cc159fa2d3c4d9ee61803b55cdd06a5/docs/src/locators.md)：定位唯一当前目标，不任取首项。
- [idb](https://github.com/jakearchibald/idb/blob/654c746bef13f9fe7f5871e03ac58015cebace5a/README.md)：事务提交后确认写入，事务中不等待网络或其他外部任务。
- [TanStack Query retryer](https://github.com/TanStack/query/blob/2fb9d905f2184a32d998da657cfcc95c381014ad/packages/query-core/src/retryer.ts)：有限退避、离线等待与取消；本脚本继续支持后台执行。
- [XState](https://github.com/statelyai/xstate/tree/8f25b68f3953a9dd3c146a76f1f4972aba092a3f)：明确等待、暂停、未决操作和保存记录故障，隔离受影响功能。
