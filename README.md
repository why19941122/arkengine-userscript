# Ark Engine 油猴脚本

奇遇、秘境与迷雾共用修仙页，远征、农场、方舟避难所与模型股市共用另一页；包含随机点击延迟、动态农场收益比较和七日本地日志。

当前版本 **v1.16.0**：避难所增加普通探险、周任务、战斗装备、训练、医疗与电台的统一调度。功能仍在远征组，每项独立开关默认关闭，在“方舟避难所 → 探险、任务与养成”保存；建设另在“发展规划与建设”设置开关、24小时废料/零件上限和保留量。

更新油猴脚本后，刷新修仙和远征两个页面，确认面板显示 **v1.16.0**。原设置保留；新增探险与养成开关默认关闭，须在远征面板展开对应模块并保存设置。

发展目标转向持续获得汽水所需的人员、补给和探险能力。先保住基础供应、已有家庭和必要医疗，再给普通探险留人，周任务使用剩余候选；按整组离岗后的产量核对20%供应余量和两小时库存。相同战力优先少损失生产，普通补岗不会挡住医疗、训练和探险位建设。属于有界候选的逐步规划，不能保证长期全局最优。

- 普通探险：默认区域0、计划6小时、携针2、保留2，均可设置；出发要求血量90%以上。计划时间至少达到网页汽水资格时长。仅召回脚本已确认派出的普通探险，血量低于60%提前召回，归来后核对容量再领取。不进入深渊或汽水加速；无法保证掉落或安全。
- 周任务：公开战力和逐关成功率公式选队，默认整程至少70%、每任务每周最多尝试1次，尝试间隔至少6小时。领取归来小队并释放人员；不把周任务当成已证实的直接汽水来源。
- 养成：出发前仅穿戴闲置战斗装备；训练力量、耐力、敏捷短板，每轮一人、提升一格后轮换，六小时后可再次入训。已有训练进度不中断，两小时仍明确为零进度才释放。医疗按智力安排值班，用针不低于保留量、每人半小时至多一针。电台依据目标人口、空床位、供应及15人时的大门值班条件安排；这不是防御成功保证。
- 建设：对应养成开启且确有可调人手时，医务室、指定属性训练室和电台进入同一预算。探险位已能用满、仍有可外出人选和补给时，逐层推进每8层增加探险位的里程碑；有空地也可下挖。区域选择只使用网页已解锁范围。

每次访问最多开工一项，点击前重新核对规划、费用、额度和保留量，之后等原请求回执与开工状态共同确认。刷新保留预算，未知结果不重发，也不释放预留额度；设置改变、人工接管或原生目标不匹配时撤销未发送操作。默认只给建议，旧设置不会自动开启消费。

新操作绑定原生请求及实际回执，未知出发跨刷新仍只核对原记录，不能因人员已外出就猜测发送成功。七日日志增加综合计划、阻塞原因、成功任务和回执报告的汽水数。关闭养成开关会停止后续操作，已安排岗位不会擅自撤销。工坊值班、复活、求援和付费操作仍由玩家处理。

发布新版时同步增加脚本版本、日志导出版本及对应测试断言，然后重新生成元数据文件：

```powershell
node -e 'const fs=require("node:fs");const s=fs.readFileSync("arkengine-auto-encounter.user.js","utf8");const h=s.match(/^\/\/ ==UserScript==[\s\S]*?\/\/ ==\/UserScript==/);if(!h)throw Error("Missing userscript metadata");fs.writeFileSync("arkengine-auto-encounter.meta.js",h[0]+"\n");'
```

验证通过且取得发布授权后，将安装脚本与元数据文件一起提交并推送到 `main`。仓库只包含脚本、说明和测试；本地运行日志及账户数据不应提交。


## 设计参考

本次借鉴以下项目的原则，使用浏览器原生 API 实现，不引入第三方运行依赖：

- [Playwright locators](https://github.com/microsoft/playwright/blob/83b80cfb2cc159fa2d3c4d9ee61803b55cdd06a5/docs/src/locators.md)：定位唯一当前目标，不任取首项。
- [idb](https://github.com/jakearchibald/idb/blob/654c746bef13f9fe7f5871e03ac58015cebace5a/README.md)：事务提交后确认写入，事务中不等待网络或其他外部任务。
- [TanStack Query retryer](https://github.com/TanStack/query/blob/2fb9d905f2184a32d998da657cfcc95c381014ad/packages/query-core/src/retryer.ts)：有限退避、离线等待与取消；本脚本继续支持后台执行。
- [XState](https://github.com/statelyai/xstate/tree/8f25b68f3953a9dd3c146a76f1f4972aba092a3f)：明确等待、暂停、未决操作和保存记录故障，隔离受影响功能。
